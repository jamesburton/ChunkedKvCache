## Gotchas
- **ResourceLock for everything heavy:** `cpu`, `cpu-bench`, `gpu`; a `cpu` lock does NOT exclude a `cpu-bench` holder: check both and keep CPU-heavy tests off while dotllm-00 agents hold `cpu-bench`; release when idle (another session holds `gpu`/`memory` for its own work). Docker in Git Bash needs `MSYS_NO_PATHCONV=1`; run Docker with `linux-ci.sh` (4 GB VM), filter e.g. `'filter:FullyQualifiedName~DotLLM.Tests.Unit.ChunkReuse'`.
- **Process-wide static test hooks race across parallel xUnit classes** (broke CI on #1648): make hooks per-flow `AsyncLocal`, never plain statics.
- **Tests must send real wire bytes** (memory `test-real-wire-bytes`). A Python/heredoc `\n` or `\u` inside a C# string turns into a real newline / a syntax error: write test files with the Edit/Write tools; never `open(p,'w')` a gitignored file before its content is built. A killed mutant runner leaves the scratch copy mutated: re-extract fresh; constant-condition mutants fail to compile (use `false.Equals(true)`); a test-host crash counts as a kill; equivalent mutants are documented, not tested around. A Windows Python cannot open `/c/...` paths: use `cygpath -w`.
- Windows vs POSIX file semantics break CI (rename under an open reader, case-sensitive globs/paths): run store/lock/ledger/index tests in Linux Docker; a mutant that only matters on Linux is verified in a Docker copy. `DOTLLM_SKIP_VULKAN=1` does not skip Vulkan unit tests.
- Default paged server path reuses prefixes across requests (#1596): a prefix-served chunk is `prefix`, not `hit`. Never merge `origin/dev` into the server research branch directly: dev into `feature/chunk-cache` first.
- Strix GPU cap: keep `DOTLLM_VK_UMA_USABLE_FRACTION` 0.64 (details in `docs/superpowers/plans/2026-11-03-strix-gpu-memory-cap-remeasure.md`).
