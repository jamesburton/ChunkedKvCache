ChunkReuse.CSharp: Roslyn symbol chunker and code corpus

## Body

Refs #1542. Follows #1577 (core library).

### Summary

New project `DotLLM.ChunkReuse.CSharp` (not packed) with the two pieces of the chunk-reuse library that need Roslyn, kept out of
`DotLLM.ChunkReuse` so the core library and `DotLLM.Server` carry no Roslyn dependency:
- **`SymbolChunker`** (`symbol-<n>`): chunks C# at method / type / field-group boundaries with Roslyn syntax; a chunk over the token
  limit is re-split at statement and member line starts, then at line starts, and a single over-long line is cut into token slices
  (those are not wire-eligible). Generated code is detected by `IsGenerated` (suffixes, `<auto-generated`, `[GeneratedCode]`).
- **`Corpus`**: a directory's C# files (bin / obj / `.git` / test directories and generated code excluded and listed with a reason,
  CRLF normalised, ordinal path order) and the chunk id hash that names the chunker.
- Wiring: core `InternalsVisibleTo DotLLM.ChunkReuse.CSharp` (`LineIndex`), `Microsoft.CodeAnalysis.CSharp` 5.9.0 in
  `Directory.Packages.props`, solution entry, unit-test project reference.
